> Modern responsive educational institute web platform providing institutional course catalogs, faculty directories, academic announcements, and student admission inquiry forms.

---

## Key Pages & Features

- **Homepage:** Hero showcase, mission statement, and featured academic programs.
- **Course Catalog (`courses.html`):** Detailed curriculum syllabi, duration, and prerequisites.
- **About Page (`about.html`):** Leadership profiles, accreditation, and institutional history.
- **Inquiry Portal (`contact.html`):** Interactive contact and admission enrollment form with client-side validation.
- **Mobile Responsive Layout:** Custom media queries ensuring accessibility across desktop, tablet, and mobile browsers.

---

## Running Locally

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/mesumali-dev/capital-institute-portal.git
cd capital-institute-portal
# Open index.html in your browser
```
